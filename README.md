# 🏨 Online Hotel Pricing & Review Intelligence Dashboard

## 🔍 Overview
This project analyzes hotel pricing, OTA presence, and customer sentiment across Indian cities using Python for data scraping and transformation, and Power BI for dashboarding. It helps hotel businesses optimize their pricing strategy and identify service gaps.

---

## 🎯 Objectives
- Track competitor hotel prices across OTAs
- Analyze customer reviews and sentiments
- Identify pricing gaps by city and star rating
- Visualize insights with an interactive Power BI dashboard

---

## 🛠️ Tech Stack
- **Python**: Web scraping (Selenium, BeautifulSoup), Data wrangling (pandas), Sentiment Analysis (TextBlob)
- **Power BI**: Dashboard design, data modeling, interactive filters

---

## 📊 Dataset
- Scraped 50,000+ hotel listings and 100,000+ reviews from Booking.com and MakeMyTrip
- Fields: hotel name, city, price/night, rating, review text, amenities, date

---

## 📈 Key Insights
- 3-star hotels in Mumbai priced ₹400–₹600 above competitors during weekends
- Negative reviews largely focused on cleanliness and check-in delays
- Gaps in OTA listing visibility across chains
